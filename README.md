# Object-Oriented Reservation System

An object-oriented implementation of a business reservation system, created as a project for the Modeling and Analysis of Information Systems (MAS) course. 

## Key Features
* **UML-Driven Development:** The system architecture directly reflects a business-case class diagram.
* **Use Case Implementation:** Full implementation of the "Making a reservation" use case.
* **Data Persistence:** Implemented data serialization to save and load system states (reservations, users, objects).

## Technologies Used
* Java 21
* Object-Oriented Programming (OOP) principles
* Data Serialization to a .txt file
